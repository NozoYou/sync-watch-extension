# 一起看：网页视频同步

Chrome 扩展支持 Mac 和 Windows。扩展后台维持房间 WebSocket 连接，因此切换标签页或导航到新视频时房间不会因页面卸载而断开。服务器转发少量播放控制状态和房间跳转决定，不转发视频画面或音频。

## 安装扩展

1. Chrome 打开 `chrome://extensions`，开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择本目录。
3. 更新代码后，在扩展管理页点“一起看”的刷新按钮，再刷新视频网页。

## 启动信令服务器

服务器默认监听 `0.0.0.0:8787`。Linux 云主机上运行：

```sh
cd /home/ubuntu/sync-watch
npm install
PORT=8787 ROOM_LIMIT=4 npm start
```

公网上建议配置域名和 TLS/WSS 反向代理，将 `wss://域名/ws` 转发到 `127.0.0.1:8787`。短期测试可填 `ws://公网IP:8787/ws`。防火墙需允许相应的 TCP 端口。

**更新服务器版本：**把本目录的 `server/server.js` 复制到云主机 `/home/ubuntu/sync-watch/server.js`，停止旧进程后重新运行上面的启动命令。`ws` 依赖没有变化，不需要重新购买云资源。

## 使用

1. 房主打开视频网页，点扩展里的“创建房间”。其他人打开对应视频页，输入同一房间码并加入。
2. 房主在已有房间时切换到含新视频的标签页，或跳转到新视频页面；页面检测到视频后会询问是否分享。
3. 房主选择“分享给房间”后，其他成员会收到系统通知，通知仅显示“房主分享了新视频”和页面标题。点击通知打开扩展面板后，可查看 URL 并选择“跟随跳转”或“不跟随”。不跟随的成员不会被跳转，也不会收到后续同步控制，直到下一次选择跟随。
4. 房间卡片会显示每位成员的跟随选择。成员关闭视频标签页不会退出房间；在扩展中点“离开”才会退出。

Chrome 扩展会在可匹配的网页 iframe 中查找 HTML5 `<video>`。DRM、canvas 播放器、浏览器禁止注入的沙盒 iframe 或非标准播放机制仍可能无法控制。所有人需要各自能访问该视频。

## 服务器和隐私

- 房间默认最多 4 人，可用 `ROOM_LIMIT` 调整。
- 播放、暂停、拖动进度、倍速等控制指令以及跳转选择会经由房间服务器传递；视频内容不经过服务器。
- 房间连接由 Chrome 扩展后台维持。请勿在 Chrome 扩展管理页点“移除”来结束房间；要退出请在扩展中点“离开”。
- 公开使用时请配置 WSS，并只把房间码分享给参与者。
