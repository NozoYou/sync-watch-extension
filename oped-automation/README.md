# 自动 OP/ED 识别

此目录包含浏览器自动流程、独立云端比对服务，以及之前的 Python 命令行流程。原 `oped-detector` 保持不变。

## 浏览器自动流程

重新加载扩展后，在功能菜单中打开“自动识别番剧片头片尾”，选择本地或云端。功能默认关闭，所有成员可自行使用，不需要房主授权；实际跳过操作仍遵循房间的进度控制权限。

当前适配 B 站番剧页面 `/bangumi/play/ep...`，以及能识别当前集的季页面。读取正片分集目录，取当前集和最近两集；第一集取后两集，最后一集取前两集。需要至少三集可访问的正片。普通视频合集、其他网站暂未适配，不会仅凭标题猜测它们是连续动画。

后台通过当前页面的登录状态请求音轨列表，选择最低码率的独立音轨，例如 `30216`。不下载视频画面，不切换前台播放器画质或音轨。每次顺序下载一集，避免三个下载同时竞争带宽；仍会消耗用户网络带宽。

- **本地浏览器**：在扩展的隐藏文档中解码音频，独立 Worker 提取特征并比对，无需 Python 或本地服务器。
- **云端服务器**：音轨获取和解码仍在浏览器完成，仅将频谱特征发送到配置的服务。服务器比对后返回时间戳。部署见 `server/README.md`。

目前下载完整的低码率音轨，每集限制 64 MB、一小时。分析开头、结尾各最多五分钟；不做整集 FFT。尚未实现只请求音轨首尾字节范围。音频不落盘到扩展存储，仅保存最终时间戳，缓存七天、最多一百集。

## 跳过行为

检测完成后，点击圆盘原有跳过按钮：当前播放位置落在已匹配的 OP/ED 内时，跳到该片段结尾。这个版本自动检测，跳过仍由用户点击触发。

片头、片尾分别判断：只匹配片头则只提供片头跳过；某集两个都没有匹配则不提供 OP/ED 跳过。不会因为另一集缺少 OP 或 ED 而直接为它复制其他集时间戳。两条证据的边界冲突时不采用该片段。

在支持的番剧页面开启识别后，尚未完成检测或当前位置没有匹配时，按钮提示没有可跳过片段，不回退到固定秒数。关闭识别或在不支持的网站使用时，继续使用原固定秒数快进。

## 文件职责

- `extension/background.js`：B 站剧集与音轨发现、任务调度、结果存储。
- `extension/offscreen.js` / `offscreen.html`：隐藏文档中的下载与音频解码。
- `extension/worker.js` / `audio-core.js`：频谱提取及重复音频比对；云端共用相同匹配代码。
- `extension/client.js`：页面切换触发检测、提供当前页面的片段结果。
- `extension/settings.js`：本地/云端配置。
- `server/server.js`：带密钥验证的独立比对服务。
- `server/record-store.js`：独立保存云端记录文件，合并同番剧中时间相同的剧集。

新检测结果可记录到云端 `server/data/oped-records.json`，包含番名、各集观看链接和 OP/ED 起止秒数，未匹配部分为 `null`。云端模式自动保存；本地模式填写云端地址和密钥后也会上传最终结果。以前仅保存在浏览器中的缓存不会自动补写。详情及文件示例见 `server/README.md`。

新增 `offscreen` 权限用于隐藏文档和 Worker；`declarativeNetRequestWithHostAccess` 用于给扩展自身访问 B 站音频 CDN 的请求设置 Referer，仅在任务期间启用相应规则。

## 已知限制

检测依靠重复音频，不理解音乐语义，重复前情或插曲仍可能误判。当前阈值为 0.96，连续匹配至少 40 秒，时间粒度约一秒。B 站接口、媒体权限或地区限制导致音轨不可访问时会显示失败，不绕过访问限制。

下载或检测失败后，同一浏览器会话不反复下载这组剧集；调整配置并重新开启识别可重试。

按本次要求未运行测试、真实下载或部署校验；不能将代码接入等同于真实网站已验证成功。云端服务尚需你部署并填写地址、密钥。

## 保留的 Python 流程

`workflow.py`、`adapters.py` 和 `catalog.example.json` 保留此前的本地目录输入方式，可读取静态 HTML 媒体源或指定 `audioUrl`，调用原 `oped-detector` 输出待审核候选。

```sh
cd oped-automation
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python workflow.py catalog.json
```

需要 Python 3.10+ 和 FFmpeg。目录示例中的 URL 需要替换。此 CLI 仅用于可信输入，不应包装成接收任意外部 URL 的公开服务；新云端服务只接收特征，不使用该下载入口。
